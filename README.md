# Game-bit
A video game console adaptation for micro:bit

Game:bit is a multi video game platform for micro:bit. The games in v1.0 are : 
Flappy bird,
Chrome dino,
Pong,
Snake,
Space Invaders,
Tetris,
Geometry dash,
Rapidity game,
Simon,
Labirynth,
Guess the number,
Tower stack,
Fishing,
Rock paper cisors,
Edge surf.

We are working every day on this project, so make sure to follow and star !
